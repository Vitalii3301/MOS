# MOS R4.2 Portable

R4.2 adds a real embedded-chat execution path on top of the verified R4.1
runtime while keeping database schema version 4.

## Added

- complete MOS Python source in GitHub rather than only a packaged payload;
- two-phase `begin-turn` / `commit-turn` host protocol;
- capture of the exact answer generated by the built-in host LLM;
- hash-verified state snapshots on the `mos-state` branch;
- Git fast-forward publication as an optimistic concurrency lock;
- preservation of losing parallel writes on `mos-conflict/*` branches;
- direct Git transport and connector-ready publication bundles;
- ChatGPT, Claude, and generic tool-enabled LLM starter instructions;
- portable state verification and CI coverage.

## Boundaries

- no external LLM API is required for embedded mode;
- MOS does not directly invoke the built-in host model from Python;
- a chat must provide Python execution and GitHub read/write access;
- schema remains version 4, so existing R4 state relay snapshots remain
  structurally compatible;
- encryption is not included in this release.
